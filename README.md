# Homebrew Scripts

Personal collection of Homebrew scripts. Most of these are probably pointless.

## Installation

```
brew tap goodpie/tap
brew install <FORMULA|CASK>
```

### Casks

| Repository | Formula | Description |
|------------|---------|-------------|
| [buildkite-notifier](https://github.com/GoodPie/buildkite-build-notifier/) | [Cask](https://github.com/GoodPie/homebrew-tap/blob/main/Casks/buildkite-notifier.rb) | MacOS menu bar application that keeps track and notifies of buildkite status' |


### Formulae

| Repository | Formula | Description |
|------------|---------|-------------|
| [git-branch-tidy](https://github.com/GoodPie/git-branch-tidy) | [Formula](https://github.com/GoodPie/homebrew-tap/blob/main/Formula/git-branch-tidy.rb) | Small script to tidy up dead branches locally |
| [bg3-prioritise-macos](https://github.com/GoodPie/bg3-prioritise-macos.git) | [Formula](https://github.com/GoodPie/homebrew-tap/blob/main/Formula/bg3-prioritise-macos.rb) | Used to prioritse the Baldurs Gate 3 process on MacOS. Helps stop crashes |
| [export-pg-db-docker](https://github.com/GoodPie/export-pg-db-docker) | [Formula](https://github.com/GoodPie/homebrew-tap/blob/main/Formula/pg-docker-helper.rb) | Small script to help export a docker table during small dev projects |
